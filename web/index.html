客观参数

相对值：数字越大占比越高，按实际数值归一化。例：竖 100 / 其余 0 = 只出竖图。 步数固定 12、种子固定随机，不再单独调。

张／天 · 填 0 = 不限
张／天 · 碰到就彻底停工

软上限：到点自动停；已经停在那条线上时，点「启动」才允许继续往上出 —— 没到线时重启不会涨额度。
硬上限：一旦碰到，怎么点启动/重启都不再出卡（产线今天下班）， 重抽不受影响，照常用。第二天零点自动复位。

尺寸比例由参数表决定（竖 55% / 窄屏 15% / 横 10% / 方 20%，12 步）；第 4 档 🧪 = 珍藏/放大档：单尺寸 1024×1536；种子可随机或固定（固定=手动填数字）。

保存后点上面的「🔄 重启」生效（改的是状态，不动版本号）。
